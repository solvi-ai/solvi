# S115: supplied domain-conditioned correlation

База11131e4, ветка codex/growth-domain-checks. Источник: archive HANDOFF.md:260–272 требует корреляцию по домену со сжатием; research_runs/modules_offline/README.md:162 требует хранить корреляцию по домену/типу ошибки и предупреждать перенос. Registry S115 не содержит executable check. Исторические GSM8K/MATH числа не воспроизводились.

Минимальное расширение существующего CorrelationAwareCombiner: optional rho_by_domain pair mappings; domain_counts и finite nonnegative domain_shrinkage задают convex shrinkage n/(n+kappa) к global rho до прежней regularization. При kappa>0 counts обязательны для всех configured domains, n<2 даёт отказ conditioned query. При kappa=0 используются supplied matrices без оценки достаточности; caller отвечает за provenance. Неизвестные domains отвергаются. None сохраняет global default и выдаёт warning при наличии domain maps. Query domain должен быть доступен до решения, без current truth/labels.

fit(obs,y) остаётся pooled likelihood estimator: отдельный domain-aware fit/автоматический estimator, correlation of signal conditional on class и label-noise marginalization не добавлялись. Ни независимость, ни calibrated posterior, ни полное закрытие S115 не заявлены. Новых public symbols нет; существующий CorrelationAwareCombiner уже экспортирован из solvi.stat и __all__.

Тесты: same observed outcomes при разных contexts получают разные weights; global defaults неизменны; input matrices копируются; unseen/invalid domain и undersampled support отказывают; shrinkage midpoint/huge finite limit проверены; existing logspace smoothing/ancestor warnings/native models сохранены. Focused test_check_domains.py + existing test_check_models.py: 65 passed (точный final elapsed в root log s115_domain_checks_20261104.log), Ruff PASS, diff-check PASS. Все pytest через memory wrapper. Full/quality eval, модели, shared/frozen source edits и push отсутствуют.

Остатки: независимое ревью и integration не выполнены. Автоматическая оценка rho по разделённым domain datasets не реализована; переданы только external validated pair matrices/counts. Quality transfer и source synthetic historic acceptance требуют отдельного protocol. Unknown/undersampled fallback только явный global None, не скрытый перенос другого domain.
