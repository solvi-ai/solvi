# Experimental: следующий прикладной шаг

Дата: 2026-11-02. Это очередь предлагаемых проверок по существующим свидетельствам, не новый результат и не разрешение на запуск eval.
Исходные ограничения: [STATUS](../src/solvi/experimental/__init__.py), [описания измерений](experimental.md), [ROADMAP](../ROADMAP.md).
Ссылки ниже ведут на локальные описания свидетельств и существующие скрипты; наличие скрипта само по себе не доказывает результат.
Когда исходный стенд не включён в репозиторий, описание не заменяет воспроизводимых сырых данных.

Приоритет — [документный процесс](development-1.4.1.md): сначала офлайн цикл с подставной моделью, затем подготовка корпуса и заморозка протокола.
Его пороги, сравнения и порядок согласования остаются без изменений. Таблица не утверждает новые численные критерии для остальных модулей.
Следующие тесты — предложения: перед каждым нужны отдельная предрегистрация, данные, метрики, бюджет и принятые критерии.
Новые прогоны для этого документа не выполнялись. Все перечисленные модули сохраняют статус **experimental**, API не удаляется.

## Что именно подтверждает проверка

- **Детерминированная проверка (deterministic verification):** цитата действительно лежит по offsets, вычисление следует коду, хеш и replay совпадают. Она относится к записи и выполненной процедуре.
- **Семантическая корректность (semantic correctness):** выбраны нужные поле, единица, правило и смысл ответа. Нужны независимая разметка или соответствующий oracle; существования цитаты недостаточно.
- **Статистическая гарантия (statistical guarantee):** ограничение конкретной ошибки при явно названных предпосылках, области, источнике меток и бюджете вероятности отказа. Replay не доказывает эти предпосылки; joint risk не заменяет ошибку среди ответивших.

Результаты пока не разрешают перенос этих модулей в stable. Для такого решения остаются отдельные ворота из [правил experimental](experimental.md): предзарегистрированный критерий, воспроизводимый скрипт, выполненный и независимо проверенный результат, отсутствие experimental-зависимостей, conformance и документация совместимости.
Отрицательный результат сохраняется; он не меняет критерий задним числом и сам по себе в этом плане не даёт команды удалять API.
