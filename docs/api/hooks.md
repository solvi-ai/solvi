# `solvi.hooks`

solvi behind a coding agent's hooks (Claude Code; Codex, preview): `solvi hook pre-edit` checks a proposed edit against
a rules file, `solvi hook pick-skill` names the skill a prompt needs, `solvi hook install` / `uninstall` write the
project's hook entries. The [guide](../guide.md#solvi-behind-a-coding-agents-hooks) walks through the setup.

::: solvi.hooks
