# `solvi.testing`

Decision regression tests from `cases.json`.

::: solvi.testing

## `solvi.testing.corrupt`

Corruption tests for specialists: how many corrupted proposals a specialist's check catches.

::: solvi.testing.corrupt

## `solvi.testing.history`

Verdicts across runs: stable / flaky / regression / fixed per case, quarantine, a known-bug registry and a run-level
"degraded" status.

::: solvi.testing.history

## `solvi.testing.mutants`

Catalog mutants: small faults made in a task file and run against its cases — the share the cases catch, and the
survivors with their lines.

::: solvi.testing.mutants
