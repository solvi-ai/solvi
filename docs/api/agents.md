# `solvi.solutions.guard`

Guarding an agent's tool calls (`solvi.Guard`): the agent proposes a call, solvi checks it and makes it. See the
[guide](../guide.md#guarding-an-agents-tool-calls). The MCP proxy that puts the guard in front of an MCP server is
experimental: [solvi.experimental.mcp](mcp.md).
