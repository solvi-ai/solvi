# `solvi.core.slow.search`

Search over alternatives: candidates (a list, a dict of domains, a depth-first `Tree`, or a space read from the facts)
run through a System's checks, the best kept by an objective, partial candidates pruned by failed hard checks and a
bound, a budget of asks, a record of what was searched and when the result is exact.

::: solvi.core.slow.search
