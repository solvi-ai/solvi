# `solvi.core.knowledge`

What a system knows across decisions, where it came from, and what rests on it: the knowledge store and its write
gates, the action model, risk policies, the agenda, the failure memory, the world map, episodes and the memory of
corrections. The guide's [Knowledge](../guide.md#knowledge-what-a-system-learned-and-from-whom) section shows how the
pieces fit; each module's page has its reference.
